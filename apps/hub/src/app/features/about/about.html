ABOUT

Built for university-scale operations, run as a personal system.

I'm a Software Developer at the Industrial University of Santander, where I build the reusable components and shared services behind the university's student, collections, and payment platforms — systems that process thousands of records with zero tolerance for downtime. My current focus sits mostly on the frontend layer: Angular architecture, component libraries, and the patterns that let a team ship features without breaking what's already in production.

Mephisto Hub exists for a simpler reason: I wanted to know what it takes to own a project end to end — not just the features inside a system someone else designed, but the architecture, the infrastructure, and every decision in between. It's a hobby that also happens to be the most honest version of my CV.
